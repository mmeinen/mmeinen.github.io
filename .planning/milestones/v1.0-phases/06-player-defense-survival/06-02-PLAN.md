3. Create `initBreakup()` function called when deathPhase transitions to 2:
   - Store `deathPos = [flyPos[0], flyPos[1], flyPos[2]]` for camera target
   - For each of 4 pieces: set position to flyPos, give random outward velocity (3-8 units/s radially outward + 1-3 units/s upward), random spin rates
   - Call `spawnExplosion(flyPos[0], 0, flyPos[2], 2.0)` for initial sparks

4. Create `updateBreakup(dt)` function:
   - For each piece: update position by velocity * dt, update rotation by spin * dt
   - Apply slight gravity pull toward black hole (optional, subtle)

5. Create `renderBreakupPieces()` function:
   - For each piece: build model matrix from position + rotation, draw with shipPg
   - Use ship color tinted slightly darker for debris

6. Create `triggerDetonationAtShip()` function:
```javascript
function triggerDetonationAtShip() {
  const slot = detSlots.find(s => !s.active);
  if (!slot) return;
  slot.pos[0] = flyPos[0]; slot.pos[1] = 0; slot.pos[2] = flyPos[2];
  slot.startSimTime = simTime;
  slot.active = true;
}
```

7. Store camera state before death: `let deathCamSaved = { az: 0, el: 0, dist: 0 };`

8. **Death sequence state machine** -- add to the render loop BEFORE ship rendering but after simDtSec computation. The state machine runs when `playerState.deathPhase > 0`:

```javascript
if (playerState.deathPhase > 0) {
  playerState.deathTimer += simDtSec;

  if (playerState.deathPhase === 1) {
    // FLICKER phase (~1.0s): ship flickers, small sparks
    // Modulate ship alpha/visibility using sin(timer*30) > 0 check
    // Spawn small explosion sparks every 0.3s
    if (playerState.deathTimer > 1.0) {
      playerState.deathPhase = 2;
      playerState.deathTimer = 0;
      deathCamSaved.az = navCamAz;
      deathCamSaved.el = navCamEl;
      deathCamSaved.dist = navCamDist;
      initBreakup();
    }
  } else if (playerState.deathPhase === 2) {
    // BREAKUP phase (~1.5s): pieces tumble outward, no ship mesh
    updateBreakup(simDtSec);
    if (playerState.deathTimer > 1.5) {
      playerState.deathPhase = 3;
      playerState.deathTimer = 0;
      triggerDetonationAtShip();
    }
  } else if (playerState.deathPhase === 3) {
    // DETONATION phase (~3.0s): volumetric explosion plays, camera pulls out
    // Lerp navCamDist outward: navCamDist += (120 - navCamDist) * simDtSec * 0.8
    navCamDist += (120 - navCamDist) * simDtSec * 0.8;
    navCamEl += (0.6 - navCamEl) * simDtSec * 0.5; // slight elevation
    if (playerState.deathTimer > 3.5) {
      playerState.deathPhase = 4;
      showGameOverScreen();
    }
  }
}
```

9. Gate ship mesh rendering on `playerState.alive || playerState.deathPhase === 1`:
   - During deathPhase 1 (flicker): render ship with alpha flicker (skip every other frame based on sin)
   - During deathPhase 2: render breakup pieces instead of ship
   - During deathPhase 3+: render nothing (detonation VFX handles it)

10. Gate shield rendering on `playerState.alive` -- no shields drawn during death.

11. Gate the existing `updateShieldPositions()` call on `playerState.alive`.

12. Gate the `playerState.stats.timeSurvived += simDtSec` on `playerState.deathPhase === 0`.

4. Create `resetCombat()` function. This is the critical restart function. It must NOT call enterNavMode/exitNavMode (to avoid planet orbit doubling). It resets:
   - Player state: `playerState.hp = playerState.maxHp; playerState.alive = true; playerState.deathPhase = 0; playerState.deathTimer = 0;`
   - Player stats: zero all stats fields, set wavesSurvived to 1 (best stats are NOT reset)
   - Shield: call `initShieldWall()` to restore all 10 pieces

   - Clear all missiles: loop `MAX_MISSILES_ACTIVE`, call `removeMissile(i)` for alive ones
   - Clear locks: call `clearLocks()`
   - Clear all enemies: loop `MAX_ENEMIES`, call `removeEnemy(i)` for alive ones
   - Clear explosions: (if there's a clearExplosions function, call it; otherwise loop the explosion SoA and set alive = 0)
   - Clear particles: (similar)
   - Deactivate all detonation slots: `for (let i = 0; i < 6; i++) detSlots[i].active = false;`
   - Reset flyPos to current orbit body position (or black hole center if no orbit), recompute flyVel for circular orbit
   - Re-spawn enemies: call `spawnTestEnemies()` (the same function used in enterNavMode)
   - Reset combat mode: `combatMode = false; selectedWeapon = 0;`
   - Reset vignette: set `--vignette-alpha` to 0
