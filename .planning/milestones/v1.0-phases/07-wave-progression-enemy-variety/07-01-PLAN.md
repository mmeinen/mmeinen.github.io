**waves.js (NEW file):**
1. Create `js/scene/waves.js` with:
   - Wave state constants: `WAVE_IDLE=0, WAVE_ACTIVE=1, WAVE_BREATHER=2, WAVE_SPAWNING=3`
   - State variables: `waveState`, `waveNumber` (starts at 0), `waveBreatherTimer`, `BREATHER_DURATION=4.0`
   - `getWaveDefinition(waveNum)` -- formula-driven wave composition:
     - `totalEnemies = Math.min(MAX_ENEMIES - 8, Math.floor(6 + waveNum * 1.2))` (reserve 8 slots for Capital minion spawns)
     - Archetype availability: Grunt always, Swarm>=3, Bomber>=5, Sniper>=8, Capital>=10 and only on boss waves or after wave 15
     - Weighted random selection: Grunt weight decreases as wave rises, harder types get increasing weight
     - Boss wave detection: `waveNum >= 10 && waveNum % 10 === 0` -- returns special boss composition with 1+ Capital ships (1 at wave 10, +1 per 10 waves above 10) plus supporting cast of hardest unlocked archetypes
     - Returns `{ enemies: [{type, count}], isBoss: boolean }`
   - `spawnWave(waveNum)` -- spawns enemies from getWaveDefinition, distributing across planets at station-keeping positions using the same pattern as spawnTestEnemies. Capitals spawn at specific planets (not random) for dramatic presence.
   - `updateWaveSystem(simDt)` -- state machine:
     - WAVE_IDLE: no-op (waits for startWaveSystem() call)
     - WAVE_ACTIVE: check if `enemyCount === 0` (excluding any lingering minions via a waveEnemyCount tracker that counts wave-spawned enemies, NOT Capital-spawned minions). When all wave-spawned enemies dead, transition to BREATHER. But also count Capital-spawned minions as wave kills so the wave does end.
     - WAVE_BREATHER: accumulate timer, show announcement, when timer >= BREATHER_DURATION: increment waveNumber, call spawnWave, transition to ACTIVE
     - WAVE_SPAWNING: immediate transition to ACTIVE (for initial wave)
   - `startWaveSystem()` -- called once to begin wave 1. Sets waveNumber=1, spawns wave 1, sets state to ACTIVE.
   - `resetWaveSystem()` -- resets to WAVE_IDLE, waveNumber=0, timer=0. Called from resetCombat().
   - `showWaveAnnouncement(waveNum)` -- sets text content and triggers CSS animation on the wave announcement DOM element. Uses `pointer-events: none` on the element. For boss waves, show "BOSS WAVE X" in a different color.
   - Difficulty scaling function `getArchetypeStats(type, waveNum)` that returns per-archetype tuning parameters: `{ detectRadius, attackRange, fireRange, accuracyNoise, attackCooldown }`. These scale with wave number per-archetype (not a single global multiplier). Snipers always high accuracy (low noise), Swarm always high aggression (short cooldown), etc. This function is the CONTRACT consumed by Plans 02 and 03 -- all archetype AI branches MUST call `getArchetypeStats(enemies.type[i], waveNumber)` instead of using hardcoded AI constants.
