**8. Insert enemy rendering into the render loop (after depth clear, BEFORE ship draw):**
Insert between line ~645 (`gl.enable(gl.DEPTH_TEST)`) and line ~647 (`gl.useProgram(shipPg)`):

```javascript
// --- Enemy instanced rendering ---
if (enemies.count > 0) {
  const liveCount = updateInstanceBuffer();
  if (liveCount > 0) {
    gl.useProgram(enemyPg);
    gl.uniformMatrix4fv(enemyLocs.uViewProj, false, _vpMat);
    gl.uniform3f(enemyLocs.uLightDir, _toLV[0], _toLV[1], _toLV[2]);
    gl.uniform3f(enemyLocs.uBhPos, 0, 0, 0); // BH at origin
    gl.uniform1f(enemyLocs.uTime, simTime);

    // Disable ray march attribute
    gl.disableVertexAttribArray(aP);

    // Per-vertex attributes (divisor 0)
    gl.bindBuffer(gl.ARRAY_BUFFER, enemyPosBuf);
    gl.enableVertexAttribArray(enemyLocs.aPos);
    gl.vertexAttribPointer(enemyLocs.aPos, 3, gl.FLOAT, false, 0, 0);

    gl.bindBuffer(gl.ARRAY_BUFFER, enemyNrmBuf);
    gl.enableVertexAttribArray(enemyLocs.aNorm);
    gl.vertexAttribPointer(enemyLocs.aNorm, 3, gl.FLOAT, false, 0, 0);

    // Per-instance attributes (divisor 1) -- interleaved in single buffer
    gl.bindBuffer(gl.ARRAY_BUFFER, enemyInstBuf);
    gl.bufferSubData(gl.ARRAY_BUFFER, 0, enemies.instanceData.subarray(0, liveCount * 9));

    const INST_STRIDE = 9 * 4; // 9 floats * 4 bytes = 36 bytes

    // a_instPos: vec3 at offset 0
    gl.enableVertexAttribArray(enemyLocs.aInstPos);
    gl.vertexAttribPointer(enemyLocs.aInstPos, 3, gl.FLOAT, false, INST_STRIDE, 0);
    iExt.vertexAttribDivisorANGLE(enemyLocs.aInstPos, 1);

    // a_instHeading: float at offset 12
    gl.enableVertexAttribArray(enemyLocs.aInstHeading);
    gl.vertexAttribPointer(enemyLocs.aInstHeading, 1, gl.FLOAT, false, INST_STRIDE, 12);
    iExt.vertexAttribDivisorANGLE(enemyLocs.aInstHeading, 1);

    // a_instColor: vec4 at offset 16
    gl.enableVertexAttribArray(enemyLocs.aInstColor);
    gl.vertexAttribPointer(enemyLocs.aInstColor, 4, gl.FLOAT, false, INST_STRIDE, 16);
    iExt.vertexAttribDivisorANGLE(enemyLocs.aInstColor, 1);

    // a_instScale: float at offset 32
    gl.enableVertexAttribArray(enemyLocs.aInstScale);
    gl.vertexAttribPointer(enemyLocs.aInstScale, 1, gl.FLOAT, false, INST_STRIDE, 32);
    iExt.vertexAttribDivisorANGLE(enemyLocs.aInstScale, 1);

    // Index buffer and instanced draw
    gl.bindBuffer(gl.ELEMENT_ARRAY_BUFFER, enemyIdxBuf);
    iExt.drawElementsInstancedANGLE(gl.TRIANGLES, enemyIdxCount, gl.UNSIGNED_SHORT, 0, liveCount);

    // CRITICAL: Reset divisors to prevent state leak to shipPg/trajPg
    iExt.vertexAttribDivisorANGLE(enemyLocs.aInstPos, 0);
    iExt.vertexAttribDivisorANGLE(enemyLocs.aInstHeading, 0);
    iExt.vertexAttribDivisorANGLE(enemyLocs.aInstColor, 0);
    iExt.vertexAttribDivisorANGLE(enemyLocs.aInstScale, 0);

    // Disable all enemy attributes
    gl.disableVertexAttribArray(enemyLocs.aPos);
    gl.disableVertexAttribArray(enemyLocs.aNorm);
    gl.disableVertexAttribArray(enemyLocs.aInstPos);
    gl.disableVertexAttribArray(enemyLocs.aInstHeading);
    gl.disableVertexAttribArray(enemyLocs.aInstColor);
    gl.disableVertexAttribArray(enemyLocs.aInstScale);
    gl.bindBuffer(gl.ELEMENT_ARRAY_BUFFER, null);
  }
}
```

**CRITICAL anti-patterns to avoid:**
- Do NOT modify fsSource (ray march shader) in any way
- Do NOT modify shipPg, shipVS, shipFS, or any existing shader program
- Do NOT call gl.bufferData on enemyInstBuf each frame (use bufferSubData)
- Do NOT forget to reset divisors after instanced draw (causes shipPg/trajPg to break)
- Enemies render BEFORE ship so depth testing works correctly (enemies behind planets get occluded, player ship draws on top)

**Existing state restoration (lines ~752-758) must still work.** The enemy rendering section cleans up its own state completely, so the existing cleanup code that re-enables aP and restores pg continues to function.
