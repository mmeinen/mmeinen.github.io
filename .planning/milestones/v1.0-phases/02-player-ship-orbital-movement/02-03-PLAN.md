**L-point rendering each frame (index.html):**

Each frame when `lagrangeVisible && flyMode`:
1. Recompute all L-point positions by calling `computeLagrangePoints(planetIndex, simTime)` for each of LPOINT_PLANETS
2. Store in `lPointPositions` flat array (12 entries, 3 floats each)
3. Render each L-point as a GL_POINTS marker using the trajPg shader program:
   - Point size: 4.0 (larger than trajectory dots)
   - Color: `rgba(180/255, 220/255, 255/255, 0.6)` (light blue, distinct from trajectory)
   - Upload all 12 positions into a dedicated `lPointBuf` GL buffer
   - Draw with `gl.drawArrays(gl.POINTS, 0, 12)`
   - Render AFTER orbit ring, BEFORE HUD update

**L-point click detection (index.html):**

Extend the nav-mode click handler (mouseup when flyMode && !dD):
- After checking hP for planet hover, if no planet hit AND `lagrangeVisible`:
  - Cast a ray from camera through click position to ecliptic plane (Y=0) -- reuse the existing `computeAimDir` approach to get ecliptic hit point
  - For each of the 12 L-points, check distance from ecliptic hit to L-point position
  - If distance < `LPOINT_MARKER_RADIUS` for any L-point, that's the target
  - Call `initiateTransfer(100 + flatIndex)` where flatIndex = planetIdx_in_LPOINT_PLANETS * 4 + lpointIdx

**L-point transfer extension (js/scene/nav.js):**

Extend `initiateTransfer()` to handle L-point targets (index >= 100):
- Decode: `flatIndex = targetIndex - 100`, `parentPlanetIdx = LPOINT_PLANETS[Math.floor(flatIndex / 4)]`, `lpointType = flatIndex % 4`
- Get L-point position from `lPointPositions` array (set by Task 1 rendering)
- Compute Hohmann delta-v from current orbit radius to L-point's distance from BH
- Apply burn same as planet transfer

**L-point SOI capture (js/scene/nav.js):**

Extend `checkSOICapture()` for L-point targets (transferTarget >= 100):
- L-points don't have a natural SOI. Use a fixed capture radius: `LPOINT_SOI = 2.0`
- When ship is within capture radius of the L-point position, circularize into a small orbit
- Add constants:
  ```javascript
  const LPOINT_SOI = 2.0;
  const LPOINT_DEFAULT_ALT = 1.0;
  const LPOINT_ORBIT_GM = 0.5; // tiny effective GM for orbiting the L-point
  ```

**L-point co-rotating orbit (js/scene/nav.js):**

When `orbitState === ORBIT_STATE.ORBITING && orbitBody >= 100`:
- Each frame in `updateAltitude`, compute current L-point world position (it co-rotates with its parent planet)
- Apply circular orbit velocity around that position using LPOINT_ORBIT_GM
- This creates a small stable orbit around the moving L-point
- Altitude adjustment (up/down keys) works the same as for planets, using LPOINT_SOI for escape and LPOINT_DEFAULT_ALT for crash reset
