**Create js/scene/particles.js:**

1. Define particle SoA store (256 slots) following the established pattern from combat.js/weapons.js:
```javascript
const MAX_PARTICLES = 256;
const PARTICLE_LIFETIME = 0.3; // seconds

const particle = {
  alive: new Uint8Array(MAX_PARTICLES),
  posX:  new Float32Array(MAX_PARTICLES),
  posZ:  new Float32Array(MAX_PARTICLES),
  velX:  new Float32Array(MAX_PARTICLES),
  velZ:  new Float32Array(MAX_PARTICLES),
  age:   new Float32Array(MAX_PARTICLES),
  r:     new Float32Array(MAX_PARTICLES),
  g:     new Float32Array(MAX_PARTICLES),
  b:     new Float32Array(MAX_PARTICLES),
};
const particleFreeSlots = [];
for (let i = MAX_PARTICLES - 1; i >= 0; i--) particleFreeSlots.push(i);
let particleCount = 0;
```

2. Implement `spawnImpactParticles(hitX, hitZ, enemyType)`:
   - Get color from `ARCHETYPE_COLORS[enemyType]` (red for Grunts)
   - Spawn 5-8 particles (5 + random 0-3)
   - Each particle: random angle (0 to 2*PI), random speed (15-40 units/s)
   - Set position to hit point, velocity from angle*speed, age=0, color from archetype

3. Implement `updateParticles(simDt)`:
   - For each alive particle: increment age by simDt
   - If age >= PARTICLE_LIFETIME: mark dead, push to free list, decrement count
   - Otherwise: update position (posX += velX*simDt, posZ += velZ*simDt)
   - No gravity (per user decision -- at 0.3s lifetime they won't travel far enough)

4. Implement `renderParticles(gl, trajPg, trajLocs, vpMat)`:
   - If particleCount === 0, return early
   - Use the existing trajectory shader program (trajPg) -- same pattern as renderProjectiles
   - Enable additive blending: `gl.blendFunc(gl.SRC_ALPHA, gl.ONE)`
   - Create a module-level render buffer: `const particleRenderBuf = new Float32Array(MAX_PARTICLES * 3);`
   - Create a GL buffer lazily on first render call (store at module level, create with gl.createBuffer + bufferData DYNAMIC_DRAW)
   - Pack alive particles: position (posX, 0, posZ) into render buffer
   - Upload via bufferSubData, draw with GL_POINTS
   - Use Grunt red color: `gl.uniform4f(trajLocs.uColor, 1.0, 0.314, 0.235, 0.8)`
   - Point size 3.0: `gl.uniform1f(trajLocs.uPtSize, 3.0)`
   - NOTE: Alpha fade per-particle cannot be done with a single uniform color. Use uniform alpha 0.8 for all particles -- the short 0.3s lifetime makes individual alpha unnecessary.
   - Reset blending after: `gl.blendFunc(gl.SRC_ALPHA, gl.ONE_MINUS_SRC_ALPHA)`
