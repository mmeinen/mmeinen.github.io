Each template's `callout` field stores the exact UI-SPEC callout text. The `isBoss` field flags VANGUARD for danger-red styling.

**`spawnFleet(template, anchorBodyIdx, basePhase)` function:**
1. Get body position via `getBodyPositionKm(anchorBodyIdx, simTime)` and radius via `getBodyRadiusKm(anchorBodyIdx)`
2. Compute `stR = bodyR + STATION_KEEP_ALT` (station-keeping radius from body center)
3. Compute `planetAngle = Math.atan2(bodyPos[0], bodyPos[2])` (body's angular position)
4. Count `totalMembers` across all composition slots
5. For each composition slot, compute role-based arc width:
   - `anchor`: arcWidth = 0 (center point)
   - `screen`: arcWidth = 0.5 radians (~30 deg spread)
   - `striker`: arcWidth = 1.0 radians (~57 deg spread)
6. For each member in each slot:
   - Check `freeSlots.length === 0` and break if full (Pitfall 1 safety)
   - Compute `phaseOffset`: if arcWidth > 0, evenly distribute members across [-arcWidth, +arcWidth] using formula: `-arcWidth + (2 * arcWidth * c / Math.max(1, slot.count - 1))`. If count=1 for a non-anchor role, phaseOffset = 0.
   - `stPh = basePhase + phaseOffset`
   - `angle = planetAngle + stPh`
   - `x = bodyPos[0] + stR * Math.sin(angle)`
   - `z = bodyPos[2] + stR * Math.cos(angle)`
   - Call `spawnEnemy(x, 0, z, slot.type, anchorBodyIdx, stPh)`
   - If slot.type is ETYPE.CAPITAL and spawn succeeded (idx >= 0): set `enemies.auxTimer[idx] = -1.0` for warp-in phase, call `spawnExplosion(x, 0, z, 4000)` if available
   - Track spawned indices in a `spawned` array
7. Return `{ spawned, centroidX: bodyPos[0], centroidZ: bodyPos[2], callout: template.callout, isBoss: template.isBoss }`

**`getFleetComposition(waveNum)` function:**
1. Compute `maxEnemies = Math.min(MAX_ENEMIES - 8, Math.floor(6 + waveNum * 1.2))` (same formula as current getWaveDefinition)
2. Handle boss waves: `isBoss = waveNum >= 10 && waveNum % 10 === 0`
   - If boss: return `[{ template: FLEET_TEMPLATES.VANGUARD }]` for wave 10. For wave 20+, return VANGUARD + SIEGE. For wave 30+, return VANGUARD + SIEGE + RAID.
3. Normal waves, based on waveNum and archetype unlock thresholds:
   - Wave 1-2: return 1 fleet: `[{ template: FLEET_TEMPLATES.PATROL }]`
   - Wave 3-4: return 2 fleets: `[PATROL, RAID]`
   - Wave 5-7: return 2 fleets: randomly pick 2 from `[PATROL, RAID, SIEGE]`
   - Wave 8-14: return 2-3 fleets: randomly pick 2-3 from `[PATROL, RAID, SIEGE]` (3 fleets at wave 10+ non-boss)
   - Wave 15+: return 2-3 fleets: VANGUARD may appear as one of the fleets (10% chance), rest from `[RAID, SIEGE]`
4. For each fleet in the returned array, compute a `scale` factor based on remaining enemy budget. If total composition members across all fleets would exceed `maxEnemies`, reduce screen/striker counts proportionally (never reduce anchor count). This prevents exceeding MAX_ENEMIES (Pitfall 1).
5. Return array of `{ template, scale }` objects where `scale` is applied to screen/striker counts in spawnFleet.

NOTE: `getFleetComposition` does NOT replace `getWaveDefinition`. Instead, `spawnWave` will call `getFleetComposition` directly instead of `getWaveDefinition`. The old `getWaveDefinition` function is kept in waves.js but will no longer be called by spawnWave (preserved for reference/potential future use).
