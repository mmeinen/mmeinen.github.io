**Add orbit state variables** after existing declarations:
```javascript
let orbitState = ORBIT_STATE.FREE;  // uses ORBIT_STATE from orbital.js
let orbitBody = -1;         // -1 = BH, 0-6 = planet index, -2 = no body
let orbitAltitude = 0;      // distance from body surface
let transferTarget = -2;    // target body index (-1=BH, 0-6=planet, -2=none)
let transferBurnDir = [0, 0, 0];
let transferBurnMag = 0;
let altUpHeld = false;      // up arrow key held
let altDownHeld = false;    // down arrow key held
```

**Add `initiateTransfer(targetIndex)` function:**
1. Set `transferTarget = targetIndex`, `orbitState = ORBIT_STATE.TRANSFER`
2. Get target body's nav-mode orbit radius (for BH: use BH capture radius 8.0; for planets: `planetData[i].oR` which is already doubled in nav mode)
3. Compute current ship orbit radius: `Math.sqrt(flyPos[0]**2 + flyPos[2]**2)`
4. Call `computeHohmannDV(shipR, targetR, BH_GM)` from orbital.js
5. Compute prograde burn direction from current velocity (flyVel normalized)
6. Apply delta-v as instant velocity change: `flyVel += burnDir * dv`
7. Store burnDir and magnitude for trajectory preview

**Add `checkSOICapture()` function** (called every frame during TRANSFER):
1. Get target body position: for BH use [0,0,0]; for planets use `planetPosAtTime(planetData[i], simTime)` (simTime is global)
2. Compute distance from ship to target body
3. If distance < `BODY_SOI[transferTarget]`:
   - Call `circularizeOrbit(flyPos, flyVel, bodyPos, getBodyGM(transferTarget))`
   - Set `orbitState = ORBIT_STATE.ORBITING`, `orbitBody = transferTarget`
   - Compute `orbitAltitude = dist - getBodyRadius(transferTarget)`
   - Clear `transferTarget = -2`

**Add `updateAltitude(simDt)` function** (called every frame during ORBITING):
1. If `altUpHeld`: apply prograde delta-v (2.0 units/s * simDt) to flyVel in velocity direction
2. If `altDownHeld`: apply retrograde delta-v (-2.0 units/s * simDt)
3. Recompute `orbitAltitude` from current distance to orbitBody
4. If `orbitAltitude < 0`: crash -- reset ship to default orbit altitude around same body (call circularizeOrbit at default altitude). Flash a warning.
5. If distance > `BODY_SOI[orbitBody]`: escape -- set `orbitState = ORBIT_STATE.FREE`, `orbitBody = -2`

**Modify `updateNav(simDt)`:**
- After existing leapfrog integration, add:
  - Remove the `if(thrusting && aimDir)` thrust block (auto-burn replaces manual thrust in transfer mode)
  - Call `checkSOICapture()` if `orbitState === ORBIT_STATE.TRANSFER`
  - Call `updateAltitude(simDt)` if `orbitState === ORBIT_STATE.ORBITING`
  - Note: keep the existing leapfrog gravity integration -- it provides N-body gravity for the transfer trajectory naturally

**Modify `enterNavMode()`:**
- After the oR doubling loop, call `initOrbitalData()` from orbital.js
- Set initial orbit state: `orbitState = ORBIT_STATE.FREE`, `orbitBody = -2`, `transferTarget = -2`
- Reset altitude flags: `altUpHeld = false`, `altDownHeld = false`
- Update NAV CONTROLS help text to include `UP/DOWN -- ALTITUDE` and `CLICK BODY -- ORBIT TARGET`

**Modify `exitNavMode()`:**
- Reset orbit state to defaults
