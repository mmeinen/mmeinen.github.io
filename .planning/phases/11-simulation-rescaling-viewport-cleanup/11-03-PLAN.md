All changes are within the `fsSource` template literal in js/scene/shaders.js. The key principle: `closeupFactor` is 0.0 at far distances (u_camDist >= 30) and 1.0 when very close (u_camDist <= 5). All modifications multiply by closeupFactor, so at far distances the shader is mathematically identical to the current version.

**Change 1: Declare closeupFactor in main() before the ray march loop.**

Find the `void main()` function. Early in main(), after the existing variable declarations and before the ray march `for` loop, add:

```glsl
float closeupFactor = smoothstep(30.0, 5.0, u_camDist);
```

Note: `closeupFactor` must be accessible in the post-loop section. It is declared in `main()` scope, so it is fine. However, `fbm()` and `diskShading()` are separate functions and cannot access it. For fbm, we will modify the early-break condition to use `u_camDist` directly. For diskShading, we will pass a parameter or use u_camDist directly.

**Change 2: Modify fbm() octave gate (line 115).**

The current line:
```glsl
if (i >= 2 && u_camDist < 50.0) break;
```

This breaks after 2 octaves when camera is close (< 50 units). We want the OPPOSITE: when very close to BH, use ALL 4 octaves for more detail. When far, the current early break at 2 octaves is fine for performance.

Replace with:
```glsl
if (i >= 2 && u_camDist < 50.0 && u_camDist > 10.0) break;
```

This means:
- `u_camDist >= 50.0`: all 4 octaves run (far from BH, current behavior)
- `10.0 < u_camDist < 50.0`: breaks after 2 octaves (medium distance, current behavior)
- `u_camDist <= 10.0`: all 4 octaves run (close to BH, NEW: more detail)

**Change 3: Enhance disk noise warp when close (line 173-174 in diskShading).**

Current:
```glsl
float warpX = noiseLUT(diskUV * 0.7);
float warpY = (u_camDist < 50.0) ? warpX * 0.7 : noiseLUT(diskUV * 0.7 + vec3(5.2, 1.3, 3.7));
vec3 warpedUV = diskUV + vec3(warpX, warpY, 0.0) * 1.5;
```

Replace the warp intensity line:
```glsl
float warpX = noiseLUT(diskUV * 0.7);
float warpY = (u_camDist < 50.0) ? warpX * 0.7 : noiseLUT(diskUV * 0.7 + vec3(5.2, 1.3, 3.7));

vec3 warpedUV = diskUV + vec3(warpX, warpY, 0.0) * warpIntensity;
```

This boosts warp from 1.5 (current) to 2.0 when very close, adding more visible turbulence structure.
