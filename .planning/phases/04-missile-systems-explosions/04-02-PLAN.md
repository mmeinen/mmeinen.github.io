  <action>
  Append billboard vertex and fragment shader strings to the END of shaders.js (after the existing enemyFS string). Do NOT modify any existing shader code.

  **Billboard Vertex Shader (billboardVS):**
  ```glsl
  attribute vec2 a_corner;       // quad corner: (-0.5,-0.5), (0.5,-0.5), (0.5,0.5), (-0.5,0.5) -- shared geometry
  attribute vec3 a_bbCenter;     // explosion world position (instanced, per-explosion)
  attribute float a_bbFrame;     // current animation frame index (instanced)
  attribute float a_bbSize;      // explosion size in world units (instanced)
  uniform mat4 u_bbViewProj;     // view-projection matrix
  uniform mat4 u_bbView;         // view matrix (for camera vector extraction)
  uniform float u_bbFrameCount;  // total frames in sprite sheet
  varying vec2 v_uv;

  void main() {
    // Extract camera right and up vectors from view matrix columns
    vec3 camRight = vec3(u_bbView[0][0], u_bbView[1][0], u_bbView[2][0]);
    vec3 camUp    = vec3(u_bbView[0][1], u_bbView[1][1], u_bbView[2][1]);

    // Billboard: offset quad corners by camera-relative directions
    vec3 worldPos = a_bbCenter
      + camRight * a_corner.x * a_bbSize
      + camUp * a_corner.y * a_bbSize;

    gl_Position = u_bbViewProj * vec4(worldPos, 1.0);

    // UV: horizontal strip sprite sheet, frame 0 at left
    // Add 0.5-texel inset to prevent frame bleeding (Pitfall 6)
    float frameWidth = 1.0 / u_bbFrameCount;
    float texelInset = 0.5 / (u_bbFrameCount * 64.0); // 0.5 texels assuming 64px frames
    v_uv = vec2(
      clamp((a_bbFrame + a_corner.x + 0.5) * frameWidth, a_bbFrame * frameWidth + texelInset, (a_bbFrame + 1.0) * frameWidth - texelInset),
      a_corner.y + 0.5
    );
  }
  ```

  **Billboard Fragment Shader (billboardFS):**
  ```glsl
  precision mediump float;
  uniform sampler2D u_bbSprite;
  varying vec2 v_uv;

  void main() {
    vec4 texel = texture2D(u_bbSprite, v_uv);
    if (texel.a < 0.01) discard;
    gl_FragColor = texel;
  }
  ```

  Use `const billboardVS = \`...\`;` and `const billboardFS = \`...\`;` following the same pattern as existing shaders in this file.

<task type="auto">
  <name>Task 2: Create explosions.js -- SoA store, procedural sprite sheet, billboard rendering</name>
  <files>js/scene/explosions.js</files>
  <action>
  Create NEW file js/scene/explosions.js with the complete billboard explosion system.

  **Explosion Constants:**
  - MAX_EXPLOSIONS = 24 (handles 18-missile salvo with some overlap from previous)
  - EXPLOSION_DURATION = 0.5 (seconds, per user decision)
  - EXPLOSION_FRAME_COUNT = 6 (frames in sprite sheet, per user decision 4-6)
  - EXPLOSION_FRAME_SIZE = 64 (pixels per frame)
  - EXPLOSION_BASE_SIZE = 2.0 (world units, ~1.2x grunt enemy scale for "1-1.5x enemy size")

  **Explosion SoA Store:**
  ```javascript
  const explosion = {
    alive:  new Uint8Array(MAX_EXPLOSIONS),
    posX:   new Float32Array(MAX_EXPLOSIONS),
    posY:   new Float32Array(MAX_EXPLOSIONS),
    posZ:   new Float32Array(MAX_EXPLOSIONS),
    age:    new Float32Array(MAX_EXPLOSIONS),
    size:   new Float32Array(MAX_EXPLOSIONS),  // allows variation in explosion size
  };
  const explosionFreeSlots = [];
  for (let i = MAX_EXPLOSIONS - 1; i >= 0; i--) explosionFreeSlots.push(i);
  let explosionCount = 0;
  ```

  **spawnExplosion(x, y, z, size):**
  - Pop from free-list, set all fields, age = 0, alive = 1.
  - Returns slot index or -1 if full.

  **updateExplosions(simDt):**
  - For each alive explosion: increment age by simDt. If age >= EXPLOSION_DURATION, remove (alive=0, push to free-list).

  **generateExplosionSpriteSheet():**
  - Create an offscreen canvas: width = EXPLOSION_FRAME_COUNT * EXPLOSION_FRAME_SIZE, height = EXPLOSION_FRAME_SIZE
  - For each frame f (0 to FRAME_COUNT-1):
    - t = f / (FRAME_COUNT - 1), progress 0..1
    - cx = f * SIZE + SIZE/2, cy = SIZE/2
    - radius = SIZE * (0.1 + 0.4 * Math.sqrt(t)) -- expanding with deceleration
    - alpha = Math.max(0, 1.0 - t*t) -- quadratic fade per user decision

    Frame rendering (per user decision: white flash -> yellow-orange fireball -> transparent fade):
    1. White-hot flash core (early frames, t < 0.4):
       - Radial gradient from center: white/pale yellow -> transparent
       - Intensity fades as t increases toward 0.4
    2. Orange/yellow fireball (all frames):
       - Radial gradient: bright yellow center -> orange -> dark red-orange -> transparent
       - Size grows with t, alpha fades with t

  - Return the canvas element (caller uploads to GL texture).

  **initExplosionSystem(gl, ext):**
  - Call generateExplosionSpriteSheet() to create canvas
  - Create WebGL texture: gl.createTexture(), gl.bindTexture(), gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, canvas)
  - Set texture params: CLAMP_TO_EDGE (both S and T), LINEAR filtering (no mipmaps)
  - Compile billboard shader program from billboardVS/billboardFS
  - Get all attribute locations: a_corner, a_bbCenter, a_bbFrame, a_bbSize
  - Get all uniform locations: u_bbViewProj, u_bbView, u_bbFrameCount, u_bbSprite
  - Create quad VBO: 4 vertices with corner coords [(-0.5,-0.5), (0.5,-0.5), (0.5,0.5), (-0.5,0.5)]
  - Create quad index buffer: [0,1,2, 0,2,3] (two triangles)
  - Create instance data buffer (pre-allocated Float32Array for per-explosion data: centerXYZ + frame + size = 5 floats per instance)
  - Store all GL objects in a module-level `bbPg` object for use by renderExplosions

  **renderExplosions(gl, ext, viewMat, viewProjMat):**
  - If explosionCount === 0, return early.
  - Pack instance data: for each alive explosion, compute frame index = floor(age / EXPLOSION_DURATION * FRAME_COUNT), clamp to [0, FRAME_COUNT-1]. Pack centerXYZ, frame, size into instance buffer.
  - gl.useProgram(bbPg.program)
  - gl.enable(gl.BLEND), gl.blendFunc(gl.SRC_ALPHA, gl.ONE) -- additive blend for bright fireballs
  - Bind quad VBO for a_corner (divisor 0 -- shared geometry)
  - Bind instance buffer for a_bbCenter (divisor 1), a_bbFrame (divisor 1), a_bbSize (divisor 1)
  - Set uniforms: u_bbViewProj, u_bbView, u_bbFrameCount, u_bbSprite (texture unit 1 to avoid conflicting with existing textures on unit 0)
  - ext.drawArraysInstancedANGLE(gl.TRIANGLES, 0, 6, liveCount) -- 6 indices for 2 triangles, liveCount instances
  - Wait -- using drawArraysInstanced with triangles requires 6 vertices (with duplicates) or use drawElementsInstanced. Since ANGLE_instanced_arrays supports drawElementsInstancedANGLE: use index buffer [0,1,2, 0,2,3] with 4 vertices.
  - Actually, ext.drawElementsInstancedANGLE(gl.TRIANGLES, 6, gl.UNSIGNED_SHORT, 0, liveCount)
  - Restore blend mode: gl.blendFunc(gl.SRC_ALPHA, gl.ONE_MINUS_SRC_ALPHA)
  - Reset attribute divisors to 0 after draw (prevent state leak -- per Phase 1 decision)

  IMPORTANT: This file is self-contained. It does NOT import from missiles.js. The connection (missile detonation -> spawnExplosion) is wired in Plan 03.

  IMPORTANT: Use texture unit 1 for the sprite sheet (gl.activeTexture(gl.TEXTURE1)) since unit 0 may be used by the blackbody or noise textures in the main shader.

  IMPORTANT: Pre-allocate ALL Float32Arrays. No `new` in the update/render loop per anti-pattern guidance.
