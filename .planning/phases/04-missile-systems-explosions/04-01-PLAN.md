  - Clear locks after firing

  **updateMissiles(simDt):**
  - For each alive missile:
    1. Validate target: if targetIdx < 0 or !enemies.alive[targetIdx], fizzle (remove without explosion)

    5. Self-destruct logic (WPN-08): When fuel <= 0 AND age > (initial fuel + MISSILE_COAST_DURATION), check dot product of velocity toward target. If negative (moving away) AND distance > MISSILE_DET_RADIUS * 3, remove silently (no explosion).
    6. Proximity fuse stays active during coast phase per user decision.
    7. BH despawn: if r < 2.0, remove.
    8. PN guidance (only when fuel > 0): Same proportional navigation as current code, but reading target position from enemies SoA instead of static targetPos.
    9. Gravity: computeGravAccel applied always (both powered and coast phases).
    10. Position update: leapfrog integration (pos += vel*simDt after vel update).
    11. Y-axis lock: posY = 0, velY = 0 (ecliptic plane).
