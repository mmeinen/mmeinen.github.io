Create `js/scene/combat.js` containing three components:

**1. Entity Store (SoA typed arrays with free-list):**

- SoA fields: `alive` (Uint8Array), `posX/posY/posZ` (Float32Array), `velX/velZ` (Float32Array), `heading` (Float32Array), `hp` (Float32Array), `type` (Uint8Array), `scale` (Float32Array)
- `instanceData` Float32Array of MAX_ENEMIES * 8 (stride: pos.xyz + heading + color.rgba + scale = 8 floats = 32 bytes per instance)
- Free-list array for O(1) slot allocation: `freeSlots` initialized with all indices in reverse order
- `count` tracking live entity count
- `spawnEnemy(x, y, z, type)` function: pops from freeSlots, sets alive=1, sets position/type/scale/hp based on archetype, increments count. Returns slot index or -1 if full.
- `removeEnemy(idx)` function: sets alive=0, pushes idx back to freeSlots, decrements count
- Archetype enum: `const ETYPE = { GRUNT: 0 };` (only Grunt in Phase 1, others added in Phase 7)
- Archetype colors: `const ARCHETYPE_COLORS = [[1.0, 0.314, 0.235, 1.0]];` (Grunt red = 255,80,60 normalized). Alpha=1.0 for glow intensity.
- Archetype scales: `const ARCHETYPE_SCALES = [1.0];` (Grunt baseline)
- Archetype HP: `const ARCHETYPE_HP = [100];`

**2. Instance Buffer Packing:**
- `updateInstanceBuffer()` function: iterates alive entities, packs posX/Y/Z, heading, archetype color RGBA, scale into `instanceData` contiguously. Returns liveCount (number of instances packed). Skips dead slots.
- Packing layout per instance (8 floats): [posX, posY, posZ, heading, colorR, colorG, colorB, colorA_glow, scale] -- wait, that's 9. Correction: use 9 floats per instance. Actually, looking at the research shader layout, it has 6 attribute slots: a_position(vec3), a_normal(vec3), a_instPos(vec3), a_instHeading(float), a_instColor(vec4), a_instScale(float). The instance data needs: vec3 pos (3) + float heading (1) + vec4 color (4) + float scale (1) = 9 floats = 36 bytes per instance. Update `instanceData` to `new Float32Array(MAX_ENEMIES * 9)` and stride to 9.

**3. Radial Bin Collision Structure:**
- `const BIN_WIDTH = 10.0;` (units per radial bin)
- `const NUM_BINS = 20;` (covers radius 0-200, sufficient for all planet orbits up to 86)
- `const MAX_PER_BIN = 16;`
- `binCounts` Uint8Array(NUM_BINS), `binEntities` Uint16Array(NUM_BINS * MAX_PER_BIN)
- `rebinEntities()` function: clears binCounts, iterates alive enemies, computes r = sqrt(posX^2 + posZ^2), bins by floor(r/BIN_WIDTH), stores entity index
- `getCollisionCandidates(r)` function: returns array of entity indices from bin(r) and adjacent bins (bin-1, bin+1, clamped to 0..NUM_BINS-1)

All variables and functions declared with `const`/`function` at file scope (no module exports -- this is a plain script tag project). The file will be loaded via `<script src="js/scene/combat.js">` in index.html (Plan 02 adds the script tag).

Create procedural angular wedge geometry for the Grunt enemy ship. Target: 50-100 triangles, angular/geometric shape language (sharp edges, flat panels, wedge hull with pointed fins). Follow the exact return format of `createBoxGeometry()`: `{positions: Float32Array, normals: Float32Array, indices: Uint16Array}`.

Ship shape design (all coordinates in local space, ship faces +Z forward):
- **Main fuselage**: Elongated diamond/wedge. Front point at (0, 0, 0.5). Rear at (0, 0, -0.4). Side points at (+/-0.2, 0, -0.05). Top/bottom ridges at (0, +/-0.08, -0.05). This gives a faceted diamond cross-section.
- **Engine nacelles**: Two angular boxes flanking the rear. At (+/-0.18, 0, -0.3), each about 0.06 wide x 0.04 tall x 0.15 deep. These give the ship a recognizable silhouette.
- **Dorsal fin**: A thin triangular fin on top. Base at z=-0.1 to z=-0.35, height 0.12 above fuselage. Sharp leading edge.
- **Ventral plate**: A flat angled plate underneath, z=-0.05 to z=-0.3, slight downward angle. Gives the ship an aggressive stance.

Each face must have its own vertices with correct face normals (not shared vertices -- same pattern as createBoxGeometry). Use flat shading normals (one normal per face, not per vertex).

Aim for 60-80 triangles total. Build the geometry face-by-face, pushing vertex positions and face normals, then triangle indices. Use a helper approach: for each triangular face, push 3 vertices (each with position + face normal), then push 3 indices.

**Append to js/scene/shaders.js -- enemyVS and enemyFS shader strings:**

Add `const enemyVS` and `const enemyFS` after the existing trajFS constant.

**enemyVS** (vertex shader for instanced enemy rendering):
- Per-vertex attributes: `a_position` (vec3), `a_normal` (vec3) -- divisor 0
- Per-instance attributes: `a_instPos` (vec3), `a_instHeading` (float), `a_instColor` (vec4), `a_instScale` (float) -- divisor 1
- Uniforms: `u_viewProj` (mat4), `u_lightDir` (vec3), `u_bhPos` (vec3), `u_time` (float)
- Varyings: `v_normal` (vec3), `v_worldPos` (vec3), `v_color` (vec4), `v_rimFactor` (float)
- Logic:
  1. Construct Y-axis rotation from a_instHeading: c=cos(heading), s=sin(heading)
  2. Rotate + scale vertex: rotated.x = (pos.x*c + pos.z*s)*scale, rotated.y = pos.y*scale, rotated.z = (-pos.x*s + pos.z*c)*scale
  3. Compute worldPos = rotated + a_instPos
  4. BH warp: toBH = u_bhPos - worldPos, bhDist = length(toBH), warpFactor = smoothstep(8.0, 2.0, bhDist) * 0.3, worldPos += normalize(toBH) * warpFactor
  5. Accretion disk glow: diskProximity = exp(-worldPos.y*worldPos.y*0.5) * smoothstep(14.0, 4.0, length(worldPos.xz))
  6. Rotate normal same way as position (no scale needed for normals since uniform scale)
  7. Set varyings, gl_Position = u_viewProj * vec4(worldPos, 1.0)

**enemyFS** (fragment shader):
- `precision mediump float;`
- Uniforms: `u_lightDir` (vec3), `u_time` (float)
- Varyings: `v_normal`, `v_worldPos`, `v_color`, `v_rimFactor`
- Logic:
  1. Normalize v_normal
  2. Directional lighting: diff = max(dot(n, u_lightDir), 0.0), amb = 0.12
  3. Rim/edge glow using archetype color: rim = pow(1.0 - max(dot(n, vec3(0,0,1)), 0.0), 2.5), rimColor = v_color.rgb * rim * 0.6
  4. Pulsing glow: pulse = 0.8 + 0.2 * sin(u_time * 3.0)
  5. Base color: col = v_color.rgb * (amb + diff * 0.85) * pulse
  6. Add rim glow, accretion disk warm glow (vec3(1,0.6,0.2) * v_rimFactor * 0.3), engine glow (back-facing: max(-dot(n, vec3(0,0,1)), 0.0) * 0.4 * v_color.rgb)
  7. gl_FragColor = vec4(col, 1.0)

Use exact same code style as existing shaders in the file (minified single-line const declarations with template literals).
