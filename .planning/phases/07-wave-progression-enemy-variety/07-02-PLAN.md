const stats = (typeof getArchetypeStats === 'function') ? getArchetypeStats(enemies.type[i], waveNumber) : null;

**Swarm AI_IDLE behavior:**

**Swarm AI_ALERT behavior:**
- Shorter alert pause: 0.2s instead of 0.5s (Swarm reacts faster). Check `enemies.type[i] === ETYPE.SWARM` in AI_ALERT and use 0.2 threshold.

**Swarm AI_TRANSFER behavior:**
- When `enemies.type[i] === ETYPE.SWARM` in AI_TRANSFER:
- Use stronger mid-course guidance (GUIDANCE_ACCEL_ENEMY * 2.0) so Swarm converges faster on the player
- Higher approach speed: after the initial transfer burn, apply a small continuous thrust toward the player (add 2.0 * dirToPlayer * simDt to velocity each frame)

**Swarm AI_ATTACK behavior:**
- When `enemies.type[i] === ETYPE.SWARM` in AI_ATTACK:
- NO projectile firing (Swarm has no ranged weapons)
- Check proximity to player: if `dist < 2.0`, deal ram damage
- Ram damage: Use `enemies.auxTimer[i]` as cooldown. Only apply damage if `auxTimer >= stats.attackCooldown` (from getArchetypeStats, expected ~0.5s at low waves, decreasing at high waves). - Flash the Swarm on ram: `enemies.flash[i] = 0.5`
- Continue accelerating toward player position even in ATTACK state (Swarm is always rushing)
- Disengage condition: if dist > 8.0 after a ram (player moved away), go to AI_DISENGAGE to loop back for another pass. Or if aiTimer > 3.0 in ATTACK without a ram, also disengage.

Best approach for auxTimer init: In spawnEnemy(), set `enemies.auxTimer[idx] = 10.0;` (a value > any cooldown, so the first trigger fires immediately). Then each archetype-specific behavior resets it after use.
