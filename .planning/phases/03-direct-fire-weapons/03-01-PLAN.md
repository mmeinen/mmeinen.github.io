  <name>Task 1: Create weapons.js -- projectile SoA, weapon configs, fire/update/hit-detect</name>
  <files>js/scene/weapons.js</files>
  <action>
Create `js/scene/weapons.js` following the SoA + free-list pattern from combat.js. The module defines all weapon logic as global functions (no ES modules -- same pattern as nav.js, combat.js).

**Constants (top of file, easily tunable):**
```
MAX_PROJECTILES = 128
KINETIC_SPEED = 80        // muzzle speed in units/s
KINETIC_LIFETIME = 3.0    // seconds before despawn
KINETIC_COOLDOWN = 1.0    // volley cooldown
KINETIC_BURST_COUNT = 5   // rounds per volley
KINETIC_BURST_DELAY = 0.05 // sim seconds between burst rounds
PLASMA_SPEED = 200        // bolt speed
PLASMA_MAX_RANGE = 120    // units before despawn
PLASMA_FADE_START = 80    // units where alpha/size fade begins
PLASMA_COOLDOWN = 2.5     // seconds between shots
HIT_RADIUS_KINETIC = 1.5  // generous hit area for kinetic
HIT_RADIUS_PLASMA = 2.0   // slightly larger for plasma bolt
```

**Combat mode state:**
```
combatMode = false
selectedWeapon = 0   // 0=kinetic, 1=plasma
```

**Weapon cooldown state:**
- `weaponCooldownEnd = [0, 0]` -- simTime when each weapon's cooldown expires
- `kineticBurstRemaining = 0` -- rounds left in current burst
- `kineticBurstTimer = 0` -- sim time accumulator for burst stagger

**Projectile SoA store (following combat.js enemies pattern exactly):**
```javascript
const proj = {
  alive:    new Uint8Array(MAX_PROJECTILES),
  posX:     new Float32Array(MAX_PROJECTILES),
  posZ:     new Float32Array(MAX_PROJECTILES),
  velX:     new Float32Array(MAX_PROJECTILES),
  velZ:     new Float32Array(MAX_PROJECTILES),
  type:     new Uint8Array(MAX_PROJECTILES),    // 0=kinetic, 1=plasma
  age:      new Float32Array(MAX_PROJECTILES),
  distTrav: new Float32Array(MAX_PROJECTILES),  // for plasma fade
};
const projFreeSlots = [];
// Pre-fill free slots in reverse order (same pattern as combat.js)
for (let i = MAX_PROJECTILES - 1; i >= 0; i--) projFreeSlots.push(i);
let projCount = 0;
```

**Functions to implement:**

1. `spawnProjectile(type, px, pz, vx, vz)` -- Pop from free list, initialize all SoA fields, increment projCount. Return index or -1 if full.

2. `removeProjectile(idx)` -- Set alive[idx]=0, push idx back to free list, decrement projCount.

3. `fireKineticBurst(simTime)` -- Guard: return if `!aimDir || simTime < weaponCooldownEnd[0]`. Set `kineticBurstRemaining = KINETIC_BURST_COUNT`, `kineticBurstTimer = 0`. Fire the first round immediately via `fireOneKinetic()`. Decrement burst remaining. Set `weaponCooldownEnd[0] = simTime + KINETIC_COOLDOWN`.

4. `fireOneKinetic()` -- Compute initial velocity: `vx = flyVel[0] + aimDir[0] * KINETIC_SPEED`, `vz = flyVel[2] + aimDir[2] * KINETIC_SPEED`. Call `spawnProjectile(0, flyPos[0], flyPos[2], vx, vz)`. CRITICAL: Must add ship velocity (flyVel) to prevent rounds flying backward relative to ship (Pitfall 1 from RESEARCH).

5. `firePlasma(simTime)` -- Guard: return if `!aimDir || simTime < weaponCooldownEnd[1]`. Compute velocity: `vx = aimDir[0] * PLASMA_SPEED`, `vz = aimDir[2] * PLASMA_SPEED`. Note: plasma does NOT inherit ship velocity (it's energy, not mass). Call `spawnProjectile(1, flyPos[0], flyPos[2], vx, vz)`. Set `weaponCooldownEnd[1] = simTime + PLASMA_COOLDOWN`.

6. `fireSelectedWeapon(simTime)` -- If `selectedWeapon === 0`, call `fireKineticBurst(simTime)`. If `selectedWeapon === 1`, call `firePlasma(simTime)`.

7. `updateProjectiles(simDt, simTime)` -- Loop all MAX_PROJECTILES:
   - Skip if not alive
   - Increment age by simDt
   - If type === 0 (KINETIC): Full gravity via `computeGravAccel([posX, 0, posZ])`. Leapfrog integration: vel += g * simDt, pos += vel * simDt. Despawn if age > KINETIC_LIFETIME or radius < 2.0 (fell into BH).
   - If type === 1 (PLASMA): Straight line, no gravity. pos += vel * simDt. Increment distTrav by speed * simDt. Despawn if distTrav > PLASMA_MAX_RANGE.
   - Handle kinetic burst: if `kineticBurstRemaining > 0`, increment `kineticBurstTimer` by simDt. When timer >= KINETIC_BURST_DELAY, fire next round via `fireOneKinetic()`, reset timer, decrement burst remaining. This scales correctly with bullet time / fast forward (Pitfall 5).
   - IMPORTANT: Use the simDt parameter (already scaled by BULLET_TIME_SCALE or FAST_FORWARD_SCALE) -- do NOT use raw wall-clock dt (Pitfall 2).

8. `checkProjectileHits()` -- Loop all alive projectiles. For each: compute radius r = sqrt(posX^2 + posZ^2). Call `getCollisionCandidates(r)`. For each candidate enemy index, check if enemy is alive, then compute distance squared. Compare against `HIT_RADIUS_KINETIC^2` or `HIT_RADIUS_PLASMA^2` based on type. On hit: call `removeProjectile(i)` and break. Do NOT apply damage (Phase 6). Leave a `// TODO Phase 6: enemies.hp[ci] -= damage` comment.

**Do NOT implement in this task (Plan 02 handles these):**
- Projectile rendering (GL_POINTS draw calls)
- Trajectory preview computation and rendering
- Trail ring buffer for kinetic tracers
- Crosshair visual rendering

The module should be functional but invisible -- projectiles exist in memory, follow physics, detect hits, but nothing draws yet.
